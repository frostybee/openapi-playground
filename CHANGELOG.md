## [1.0.0] - 2026-02-24

### Added

- Swagger UI and RapiDoc documentation viewers.
- File upload support for OpenAPI schemas (JSON, YAML).
- Section for listing and managing existing uploaded OpenAPI schemas.
- RapiDoc look and feel customization controls.
- CSRF protection for form submissions.
- Rate limiting support for upload and delete operations.
- Session-based file handling to prevent reupload on page refresh.
- Proxy endpoint for testing localhost APIs without CORS restrictions.
